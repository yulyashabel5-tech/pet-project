# Аутентификация

Для доступа к API требуется токен доступа. Токены выдаются вручную и приходят на электронную почту.

## Как получить токен

1. Проверьте электронную почту на наличие письма от команды Documentat.

2. В письме найдите строку с токеном (длинная последовательность символов).

3. Скопируйте токен. Он понадобится для всех запросов к API.

!!! warning "Важно"
    Токен относится к **конфиденциальным учётным данным**, поэтому:
    
    * не выкладывайте токен в репозиторий и не фиксируйте в коде;
    
    * не пересылайте токен в чатах или по почте третьим лицам;
    
    * не храните токен в открытых файлах проекта.

## Как использовать токен

Добавьте заголовок `Token` со значением токена к любому запросу:

```bash
curl -X 'GET' \
  'https://api.documentat.io/api/dev/users?limit=1' \
  -H 'accept: application/json' \
  -H 'Token: ВАШ_ТОКЕН'
```
